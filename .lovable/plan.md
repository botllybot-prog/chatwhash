

# إضافة تغيير كلمة المرور في لوحة صاحب المحطة

## التعديل

إضافة تبويب "الحساب" في `StationPortal.tsx` يحتوي على نموذج تغيير كلمة المرور باستخدام `supabase.auth.updateUser({ password })`.

## التفاصيل

**ملف واحد يُعدّل: `src/pages/StationPortal.tsx`**

1. إضافة مكون `AccountTab` جديد يحتوي على:
   - حقل كلمة المرور الجديدة
   - حقل تأكيد كلمة المرور
   - تحقق أن الحقلين متطابقين وأن الطول >= 6 أحرف
   - زر "تغيير كلمة المرور" يستدعي `supabase.auth.updateUser({ password })`
   - رسالة نجاح/خطأ عبر toast

2. إضافة `TabsTrigger` جديد باسم "الحساب" مع أيقونة `Key` في شريط التبويبات
3. إضافة `TabsContent` يعرض `AccountTab`

**لا يحتاج migration أو تعديل قاعدة البيانات** — يستخدم Supabase Auth API مباشرة.
