

# تحويل التطبيق لتصميم موبايل مع قائمة سفلية

## الفكرة العامة

تحويل الواجهة العامة (للسواق/المستخدمين) لتبدو كتطبيق جوال حقيقي مع شريط تنقل سفلي (Bottom Tab Bar) يحتوي على أيقونات، وزر واتساب بارز في الوسط.

```text
┌─────────────────────────┐
│     محتوى الصفحة        │
│                         │
│                         │
├─────────────────────────┤
│  🏠   📋   💬   🗺️  ⚙️  │
│ الرئيسية المحطات واتس الخريطة المزيد│
└─────────────────────────┘
              ↑
        زر واتساب بارز (FAB)
```

## الصفحات الجديدة / المعدّلة

### 1. `src/components/MobileLayout.tsx` (جديد)
- Layout wrapper يحتوي على Bottom Navigation Bar
- 5 عناصر: الرئيسية، المحطات، واتساب (وسط بارز)، الخريطة، المزيد
- زر الواتساب في الوسط يكون أكبر ومرفوع (floating) بلون ocean-500
- يُخفي الشريط السفلي في صفحات الأدمن
- يظهر فقط في المسارات العامة (`/`, `/stations-list`, `/map`)

### 2. `src/pages/StationsList.tsx` (جديد)
- صفحة قائمة المحطات المسجلة للسواق
- كروت جميلة لكل محطة تعرض: الاسم، العنوان، ساعات العمل، حالة (مفتوح/مغلق)، صورة المحطة
- بحث بالاسم/العنوان في الأعلى
- الضغط على محطة يفتح تفاصيلها (خدمات، مواعيد متاحة، أزرار الملاحة)
- تصميم mobile-first بكروت عمودية

### 3. `src/pages/LandingPage.tsx` (تعديل)
- تبسيط الصفحة الرئيسية لتبدو كشاشة ترحيب موبايل
- إزالة الـ Navbar العلوي التقليدي (يُستبدل بالقائمة السفلية)
- إبقاء المحتوى التسويقي مع تحسينه للموبايل

### 4. `src/pages/StationsMap.tsx` (تعديل بسيط)
- إضافة padding-bottom للخريطة لتجنب تداخل القائمة السفلية
- تعديل أزرار البحث والرجوع

### 5. `src/App.tsx` (تعديل)
- إضافة مسار `/stations-list` جديد
- لف الصفحات العامة بـ `MobileLayout`

## التفاصيل التقنية

### Bottom Navigation Bar
- `fixed bottom-0` مع `z-50` و `safe-area-inset-bottom`
- خلفية `bg-card` مع `border-t` و `backdrop-blur`
- 5 أيقونات من lucide-react: `Home`, `List`, `MessageCircle`, `Map`, `MoreHorizontal`
- زر الوسط (واتساب) بتصميم FAB: دائري، أكبر حجماً، مرفوع `-translate-y-4`، يفتح رابط واتساب مباشر
- رقم الواتساب يُقرأ من `app_settings` (مفتاح `WHATSAPP_BOT_NUMBER`)
- Active state للصفحة الحالية بلون `ocean-500`

### صفحة قائمة المحطات
- تجلب من `stations` حيث `is_active = true`
- كل كارت يعرض: صورة (أو placeholder)، الاسم، العنوان، ساعات العمل، Badge مفتوح/مغلق
- بحث فوري بالاسم والعنوان
- الضغط على كارت → يفتح sheet/drawer بتفاصيل المحطة (خدمات + مواعيد + أزرار ملاحة)
- نفس منطق `StationCard` من `StationsMap.tsx` يُعاد استخدامه كـ component مشترك
